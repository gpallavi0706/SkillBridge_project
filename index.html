How to connect in 3 steps:

        
    
          
  1. Import in MySQL Workbench: Open MySQL Workbench, click File > Open SQL Script..., select backend/schema.sql, and click ⚡ (Execute) to create skillbridge_db and seed data.
    2. 
          
  2. Check Credentials: In backend/.env, confirm your DB_PASSWORD matches your MySQL root password.
    3. 
          
  3. Start FastAPI: In terminal, run:
            
    cd backend
.\run.ps1
    
          
    4.
